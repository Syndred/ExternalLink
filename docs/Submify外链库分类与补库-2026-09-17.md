# Submify 外链库分类与补库交接

日期：2026-09-17
版本：3.5.0
提交：`be42b70 feat: 在侧栏加入分类外链库`

## 1. 本轮目标

- 参考 Submify 侧边栏的信息架构，在 ExternalLink 侧栏增加独立「外链」入口。
- 不复制其界面，在现有视觉体系中补齐分类、搜索、费用筛选和质量摘要。
- 对比 Submify 当前公开外链库，把 ExternalLink 缺少的条目补入 Neon 云端唯一真相源。
- 识别功能差距，并保留 ExternalLink 的证据账本、Profile 隔离和自动提交安全闸门。

## 2. 已完成

### 侧栏外链库

- 顶部标签调整为「执行 / 外链 / 批量 / 待人工」。
- 外链页支持名称、域名和标签搜索。
- 分类筛选支持：AI 工具目录、启动发布、SaaS / 软件目录、应用目录、企业 / 本地目录、内容 / 客座投稿、社区 / 论坛、设计 / 作品展示、社交 / 资料页、其他目录。
- 费用筛选支持：免费、免费增值、付费、待核验。
- 卡片显示名称、域名、分类、费用、语言、DR、自然流量、当前 Profile 的提交状态和站点标记。
- 默认每次显示 60 条，可继续加载；「完整管理」直接进入 Settings 外链库。
- Settings 外链库同步增加同一套分类筛选和元数据展示。

### Submify 补库

- 读取 Submify 当前公开接口的 100 条已审核外链，并按规范化域名与现有云端 2,905 条逐项去重。
- 30 条已存在，70 条缺失；只把 70 条缺失项写入 Neon，没有改动离线种子 `table-library.json`。
- 云端二次回读结果：2,975 条外链、65 条站点标记；`sheetTableData` 修订 8，`siteAnnotations` 修订 42。
- 29 条社区、论坛、反馈或内容发布类条目标记为 `skip`，保留在库内供人工查阅，但不会进入自动队列。
- 2 条收费条目标记为 `paid`；其余 39 条保留为普通候选，提交前仍执行登录、验证码、付费、适用性和回执检查。

## 3. 与 Submify 的功能差异

| 功能 | Submify | ExternalLink 当前状态 | 建议优先级 |
| --- | --- | --- | --- |
| 侧栏外链分类检索 | 有 | 本轮已补齐，并额外显示 Profile 状态与站点标记 | 已完成 |
| 收藏与公共 Backlink Plaza | 有 | 有统一私有库和人工标记，但没有公共广场与个人收藏层 | P1 |
| 快速批量打开 URL | 有，可设批量数、间隔并移除已打开项 | 当前以持久批次执行为主，没有轻量 URL 打开器 | P1 |
| 快捷填表 | 有字段快捷键、单字段 AI 和多语言生成 | 有确定性填表、字段学习和 AI 补缺，但没有键盘面板与单字段多语言生成 | P0 |
| CSV 导入导出 | 有 | 有 JSON 备份、执行报告和云端快照，没有用户侧 CSV 工作流 | P1 |
| AI 工作台与任务历史 | 有对话式任务入口 | 有复杂页面视觉兜底和详细执行账本，但没有自由对话式工作台 | P2 |
| Codex 任务提示/API 入口 | 有 | 有本地 Operator Skill，没有产品内提示生成器 | P2 |
| 主题与中英文界面 | 有系统/亮/暗及中英文 | 当前为中文亮色 | P2 |
| 账号、额度、会员 | 有 SaaS 账号体系 | 当前为自托管 Neon/R2，无账号额度层 | 暂不需要 |
| 启动计划、客座投稿、白标报告 | 官网列出相关模块 | 有 Product Hunt 专项和运营报告，但没有统一启动计划、外联 CRM、白标客户报告 | P2 |

ExternalLink 现有优势仍保留：`destinationKey + Profile` 证据账本、提交/待审核/公开上线分级、R2 媒体、可恢复批次、人工页签保留、冲突保护、失链监控和新回执成功闸门。

## 4. 验收结果

- `node --test tests/*.test.mjs`：42/42 通过。
- 新增分类器单测覆盖 AI、启动发布、客座投稿、社区、费用、标签和指标归一化。
- 本地 HTTP 视觉壳已实际打开侧栏并点击「外链」，确认标签、筛选、说明和错误态布局可见。
- Neon 已完成真实写入并由 `/v1/snapshot` 二次回读，70 条来源为 `submify-public` 的新条目全部存在。

## 5. 尚待实机确认

当前浏览器仍加载旧扩展代码；自动化工具不能直接访问 `chrome-extension://` 内部页。因此本轮不能把「Chrome 已重载 3.5.0、侧栏真实读出 2,975 条」报告为完成。用户在扩展管理页重载后，需要在 Settings 的云端数据中心点击一次「从云端回读」，再打开侧栏「外链」确认分类数量和卡片显示。

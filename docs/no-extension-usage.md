# 无扩展版使用说明

## Windows 现在使用

双击 `executor/打开外链助手.cmd`。它复用本机已有配对并打开 Chrome 工作台；已打开时也可访问 `http://127.0.0.1:19389/`。若提示未连接，重新双击启动入口取得本机会话，无须安装或重载扩展。

- **我的网站**：选产品编辑资料并保存；新增产品填写名称和官网。产品详情上传 Logo、封面或截图，支持 PNG/JPEG/WEBP，每张最多6 MB。每次上传保留独立版本；可停用媒体或恢复旧版。归档产品保留原投稿历史。
- **外链库**：搜索、导入、编辑或标记站点状态。离线编辑先保存本机；云端恢复后回读。出现同步冲突，比较两边后选择“保留云端”或“采用本机编辑”。
- **提交总览**：查看站点×产品组合、收件及审核状态。收到邮件不等于审核通过或上线。
- **运行任务**：查看原任务、预算和待人工原因。当前固定30仍暂停13/30；“继续固定批次”“运行原任务”会发起投稿，应在你决定恢复投稿时再使用。结果未知的任务先核验，不能重建任务重投。
- **Gmail 只读连接**：当前Windows已连接，后台每分钟同步。可手动“同步邮箱”或“验证令牌续期”。现在Google Testing授权有效至2026-10-07，提示需要授权时再走本机Google授权。只读，不发送或修改邮件；长期续期尚未实测。

Codex当前连接已有14个统一工具，可直接说“查看某个产品资料”“查看原任务进度”“同步Gmail”“修改这个产品的介绍”。你未允许投稿前，助手只处理管理/读取，不恢复投稿。

## Mac 预留入口

用户已于2026-09-30决定：Mac先保留支持，使用时有问题再修。下面入口和平台分支已有源码及回归覆盖，**尚未在实体Mac验收**。

使用本次提供的源码预览包，或在仓库中拉取这次重构提交后运行。预览包解压到自己的目录；不要把Windows的`node_modules`、SQLite或浏览器登录目录复制到Mac。每台电脑保留自己的设备配对及Gmail本机授权。

Mac需要已安装Node.js 24.21或更新版本、npm和Google Chrome。终端进入解压后的ExternalLink目录，首次运行：

```bash
bash executor/连接云端.command
```

入口安装本机依赖，使用你的Cloudflare账户登记当前Mac设备，然后打开同一云端工作区。首次没有Cloudflare登录时会打开授权页面。若本机有已有设备配对则复用，不覆盖旧台账。新设备初始化保持暂停。Gmail要在Mac工作台单独导入自己的Google桌面客户端JSON，并点击“开始本机只读授权”；不复制Windows系统凭据。

以后打开工作台：

```bash
bash executor/打开外链助手.command
```

Mac的资料/库/收件数据来自同一云端；本机邮件缓存、浏览器登录和运行恢复点分别保留。当前Mac入口可供资料管理、邮箱配置及状态查看。Mac实际执行投稿、专用Chrome登录恢复和长期Gmail仍需使用时实测，不把Windows的314项测试当成Mac验收。

若打开失败，把终端显示的错误或 `~/.externallink-executor/workbench-error.log`、`d1-server-error.log`、`watchdog.log` 中相关错误交给助手处理即可；保留 `~/.externallink-executor`，不要通过清空本机目录解决问题。

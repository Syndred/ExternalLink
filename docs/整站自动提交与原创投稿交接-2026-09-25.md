## 插件代码能力

- 普通目录表单原有能力包括站点 × Profile 排队、规则填表、模型补缺、可识别控件选择、普通免费表单代点、回执识别、精确本地账本与时间线。仅填表、验证码、登录、付费、自定义控件或未知回执仍依各自闸门处理。
- 本轮新增活动表单的法律同意检测：未勾选的必选法律复选框，以及明确声明“提交/继续即同意条款”的文案，会阻止自动最终点击；模型动作和通用选项填充也不会代勾法律条款。页脚普通条款链接不作为当前表单同意。
- 成功后关页和推进队列已增加云端回读闸门。只有站方回执、本地精确账本、Neon 精确记录与时间线均核对成功，才可标记完整自动闭环；云端故障时保留本地回执和页签，再次运行先识别已存记录，避免重复提交。
- 云端稍后恢复时，后台会复核精确站点 × Profile 记录和对应动态。批次自动解除这项成功记录的等待并续跑；侧栏仅在原归属页签、当前 Profile、实际回执页 URL 仍匹配且能安全关页时打开下一站。页签关闭失败则停留，不抢开下一站。

- “整站自动完成”仅指适用的普通免费目录在无人工门槛、提交规则允许、表单控件受支持且有可核验回执时完成从填写到云端记账的闭环。不同站点的验证码、登录、邮箱确认、法律条款、付费或非标准控件，仍需要人工接管或单站适配。AI Tools Directory 明确属于人工原创投稿。

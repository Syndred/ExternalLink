# 外链提交验收与误填保护

日期：2026-09-24

## 本轮目标与实际结果

原目标是按已有真实成功记录的站点优先，为 JevPlay、OldPhotoLive AI、Graffiti Name AI 各提交至少 30 个站点，并验收插件是否自动填写、提交和记账。

本轮只试跑了 3 个 Graffiti Name AI 组合。三个候选站均未找到可由确定性规则处理的目录表单，插件转交模型后收到 `Insufficient Balance`，随后按无人值守组合上限暂停。没有站点实际提交成功，也没有验证码。JevPlay 和 OldPhotoLive AI 尚未进入试跑；本轮未达到 30 站目标。

Future Tools 首页是 AI 新闻订阅页，不是产品提交表单。插件误将配置邮箱填进了 newsletter 邮箱框；已清空该字段，未点 `Subscribe to Newsletter` 或其他订阅按钮。备份回读未见本轮三个域名对应的提交记录或时间线事件，因此没有虚报成功。

## 源码修复

- email-only 表单不再作为产品提交表单的识别证据。
- 识别 newsletter / subscribe 等营销语义的单邮箱表单，并从表单范围、填表候选中排除。
- 侧栏自动填表和批次后台自动填表均要求页面被识别为 directory、submission、profile 或 forum；未知页面即使有输入框也不自动填。
- 扩展 Manifest 升至 3.7.4，方便重载后确认修复版本。
- 增加 newsletter、目录表单、联系表单的行为回归用例。
- 补上模型服务商额度错误的明确处理：Worker 将 `Insufficient Balance` / HTTP 402 映射为 `AI_PROVIDER_BALANCE_EXHAUSTED` 和 503；插件保留错误码并显示中文原因，不再把它混成普通云端错误。Worker 已部署，版本 `d6e24727-7cf8-47f0-981b-1edafdafdd05`。
- 额度问题来自 DeepSeek 账户状态，插件代码无法恢复余额；恢复额度前，仍依赖 AI 才能识别的非标准表单会停在人工处理状态。

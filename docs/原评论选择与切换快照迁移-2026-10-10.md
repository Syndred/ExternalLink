# 原评论选择与切换快照迁移

原插件 selectCommentDraft 会在切换候选前保存当前编号、文本、语气及整组候选。此前当前界面仅有并列候选的复制和填入按钮，缺少选中编号与自动切换快照。本次为每张卡片增加「选择候选」，在切换前保存，并在显式保存、历史恢复及页面重开时保留选中编号。

| 原入口 | 当前入口 | 操作与持久化结果 |
| --- | --- | --- |
| renderCommentDrafts / selectCommentDraft | AI 评论 → 选择候选 1、2、3 | aria-pressed 显示选中状态；再次选择同一候选不新增快照 |
| captureCommentState / makeCommentSnapshot | 选择另一候选之前 | 将原选中编号、文本、语气和全组候选写入按工作区、产品及文章隔离的 SQLite commentHistory |
| restoreCommentHistory | 恢复上一版／载入最近草稿／历史条目 | 恢复选中编号与全组候选；当前编辑保存后再恢复；原快照仍保留 |
| 原临时编辑与显式保留 | 保存编辑后的草稿 | 保存当前选择及对应编辑文本；SQLite 重开与实际页面重载回读相同 |

实际隔离浏览器按原顺序编辑三个候选并切换两次，运行冻结原完整 selectCommentDraft、captureCommentState 及关联处理函数。两份切换前快照逐项且按顺序比较 selected、text、tone 与 drafts 全部元数据；最终显式保存的选中编号、文本及候选一致。另验证保存失败保留选择与编辑、无效编号拒绝且不写入、恢复上一版恢复编号、SQLite 重开和实际界面重载。

空候选或仅空白的当前评论在切换时不创建快照；相同文本、语气及整组候选文本按原 commentSnapshotKey 去重，不因编号改变重复归档。切换、恢复及重新生成前的快照保留原来源标签，历史入口显示这些标签。空候选及相同内容去重均有实际界面和完整原函数对照证据。

保留旧历史读取兼容性。旧调用未传 selected 时不强加新字段；通过新增选择入口保存的快照携带编号及文本。切换前自动保存与显式保存当前版本分别对应原快照及当前编辑状态。

16 项相关测试通过。最终固定代码的全量回归 1114 项通过，0 失败、0 取消、0 跳过，耗时 479586.6935 ms。代码提交 76b6da4 已推送，原服务 19388／19389 经保护检查更新；实际服务提供对应界面源码，后端无效编号拒绝且原评论历史哈希不变。原生产账本哈希不变，固定批次保持暂停 13／30。

首轮串行测试因补修分支而停止；中间一轮 1114 项通过但期间修改了分支代码，两者均保留且不计为最终发布证据。完整结果见同名证据目录 summary.json。此次未修改 Worker。原生产来源、账本和暂停批次需在更新前后保护检查；原 Chrome 不操作，生产只核验服务源码和拒绝无效编号的零写入分支。

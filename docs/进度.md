## 1. 已确认工作流

用户先勾选一个或多个自家网站 Profile，再按外链站分组执行。每个外链站只打开一次，组内按勾选顺序逐个提交尚未成功的 Profile。

示例：

- 本轮选择 B、C。
- D 已有 `D × B = success`，因此 D 只提交 C；C 成功后写入账本。
- E 没有历史记录，因此同一页签依次提交 B、C。
- 下一轮 D 的 B、C 均已有成功记录，整个 D 分组跳过。

## 2. 当前架构与真相源

| 数据           | 真相源                              | 说明                                                       |
| -------------- | ----------------------------------- | ---------------------------------------------------------- |
| 自家网站资料   | `siteProfiles`                      | 使用稳定 Profile ID                                        |
| 本轮多选       | `selectedSiteIds`                   | 记住最近选择                                               |
| 永久成功       | `submissionRecords` v2              | 唯一键 `destinationKey + profileId`                        |
| 外链站状态     | `siteAnnotations`                   | `paid/broken/skip/deleted` 永久排除；登录/验证码仅临时闸门 |
| 运行批次       | `activeBatchRun`                    | 只恢复 running / waiting_manual / paused                   |
| 人工维护源     | Neon 云端工作区                     | 网站资料、外链库、分类、账本、时间线；扩展自动同步           |
| 离线安装种子   | `Table.xlsx` / `table-library.json` | 仅首次安装和回滚，不要求日常维护                            |

永久成功只允许两种来源：

1. Agent 看见成功页、成功文案等明确证据。
2. 用户人工点击“确认成功”。

# 原队列置顶与回复丢失上传恢复验收

原后台 pinLibraryUrl 将自定义网址列表中同一原站点键的最早一行置于首位，保留其网址和分类标记，移除同键的其他行；没有既有行时加入网址及 directory 分类。本轮实际点击外链库十类原域名别名的队列置顶按钮，逐次对照冻结原完整函数及全部文档，并检查编辑面板的置顶入口。

置顶不修改收藏、分组、表单知识、删除标记、表格、产品和历史收件。列表的置顶优先显示选项另由偏好保存控制；本轮保持原偏好未变。十类界面测试使用固定域名清单，没有为提高通过率替换失败项。

实际界面离线保存一次置顶修改，磁盘重开后使用同一修改编号；点击设置与备份中的上传本机待同步修改，受控云端保存后丢失回复。原上传流程随后只比较版本，导致这条已保存修改被错判为冲突。本轮修复为先回查已尝试写入且结果不确定的本机修改，完整结果匹配时确认，不再次发送；未匹配、未尝试或工作区变化均不自动确认。

修复后再次从磁盘重开并点击同一上传按钮，只读回查后该修改确认，置顶写入合计一次，重复写入零次。最终磁盘及实际编辑面板回读确认收藏、显示偏好和归档标记保留。相关检查还覆盖收藏、站点标记和默认设置的已保存回复丢失恢复，以及结果不同、从未尝试和工作区切换的负面分支。

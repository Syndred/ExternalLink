# 云同步状态可见性（2026-09-23）

## 本轮改动

- 设置页的“轻量核对版本”只请求一次 `/v1/revisions`，对比云端修订与本机已保存修订；不为状态检查下载 `sheetTableData` 等文档正文。
- 外链库右栏直接显示同步状态与“轻量核对版本”，不用展开配置区。明确显示“版本一致”“本机待上传”“冲突”“修订不一致”“空工作区”五类结果，以及检查、上次回读和上次上传时间。设置页尚未保存的编辑单独提示，不算作已同步。
- 按钮改为“轻量核对版本”“回读云端更新”“重试上传本机修改”。无变化的回读显示“云端没有新更新”，避免“更新 0 类”被误解。上传后继续显示真实版本状态，冲突不再被绿色成功提示掩盖。
- 提示说明正常改动会自动上传；打开设置可能增量回读有变化的提交记录和时间线；新设备首次回读或明确确认覆盖本机数据时，仍可能读取完整云端数据。

## 实际读写边界

- 本轮仅修改扩展状态查询和界面文案，没有修改 Worker 接口或云端数据。轻量核对会产生一次小型 Neon 修订号查询；不会触发全量快照。
- 日常增量回读仍是先查修订号，再只读取变更的文档；侧边栏提交动态有 60 秒冷却。配额错误仍按 60 分钟退避。
- “版本一致”仅表示核对时本机已保存文档修订与云端一致，且无待上传或冲突；不是保证之后其他设备不会继续修改。完整数据内容是否在 Ego 界面正确显示仍需扩展重载后的现场回读。

## 台式机以 Neon 为准续办

1. **先完整退出台式机上的 Ego/Chrome**，使旧版扩展不再运行。然后在台式机既有 ExternalLink 仓库运行 `git status --short`，确认本机改动后运行 `git pull --ff-only origin main`；扩展清单应为 `3.7.45`。拉代码只更新扩展文件，不会自动更新浏览器缓存或 Neon 数据。
2. 确认台式机已安装扩展的来源目录就是刚拉取仓库的 `extension/`，然后启动浏览器并在扩展管理页点击“重新加载”，核对已加载版本为 3.7.45。若来源目录不同，先核对实际加载目录并在原安装目录更新代码；不要直接卸载旧扩展，以免清除本机缓存和连接配置。`table-library.json` 不是资料正本。
3. 打开 ExternalLink 设置 → 外链库 → 本机与云端同步，点“轻量核对版本”。工作区应为 `default`；若显示待上传或冲突，先记录具体数据类。3.7.45 会暂停旧队列的自动上传。展开“云端、备份与监控”，点“回读云端更新”。若弹出本机待保存/冲突提示，插件会先发起 JSON 备份；确认备份落盘后，按页面提示选择以云端替换本机对应数据。**不要点“首次迁移到云端”或先点“重试上传本机修改”。**
4. 回读后再点“轻量核对版本”，应显示“本机已保存数据与云端版本一致。待上传 0 类，冲突 0 类”。在网站资料查看 OldPhotoLive AI：免费额度为 1 张/日，一次性积分包为 $4.99/10、$9.99/25、$19.99/60，没有旧月订阅说法。云端 `siteProfiles` 本轮只读复核已到修订 90；修订号可能继续增长，若界面仍是旧文案，先不要继续该 Profile 的提交。

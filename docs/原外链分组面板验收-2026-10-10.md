原入口为设置页 `createLibraryGroupPanel` 生成的两个分组按钮；当前入口为「外链库 → 编辑 → 收藏、启用与分组」，勾选后点击「保存收藏与分组」。已拉取云端最新代码。

冻结原版本 `bd916b2944a577b160a6afcb8a7d73d263044c0c` 的完整面板函数、标记归一函数及 queue、library-classifier、library-groups 三个完整模块参与比较。两分组分别为「高质量优先」「免费可提交」。

| 原站点状态 | 当前操作及结果 |
| --- | --- |
| 自动分组 | 实际编辑窗口的分组选择与原面板一致；只改收藏不会将推断分组写成显式选择。 |
| 付费 | 免费分组禁用，提示与原面板一致；其他分组继续按原条件判断。 |
| 网址失效、跳过、归档 | 两个分组均禁用，不作为有效分组成员；已有分组记录保留。 |
| 禁用站点 | 分组禁用且不选中；改收藏不删除已存分组，启用后恢复有效成员显示。 |
| 显式空分组 | 不自动加入推断分组。 |
| 显式两分组 | 显示两个已选分组。 |

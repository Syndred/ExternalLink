# 外链库界面自动联动

源码版本：3.4.7。

## 修复范围

侧栏与设置页共用扩展存储中的外链库、标记、提交记录与动态。原先侧栏监听存储变化，设置页只在打开或自身操作后读取，因此侧栏修改后需要手动刷新设置页。

本轮为设置页补齐存储监听和自动更新，合并连续变更，防止旧请求晚到覆盖新结果。刷新保留筛选条件、选中站点和未保存编辑；新增监听只读取和更新界面，不新增云端写入逻辑。

这是同一 Chrome 扩展实例内的界面联动。既有云端上传、回读、离线队列和冲突处理路径不变，不代表不同设备之间新增实时推送。

## 验证

`node --test tests/*.test.mjs`：41/41 测试文件通过；`node --check extension/settings.js` 与 `git diff --check` 通过。新增回归执行真实源码函数，覆盖双方向监听、无关事件忽略、连续变更合并、旧结果淘汰、初始化并发、Profile 草稿、动态编辑器与焦点保留、保存清理顺序及失败不丢输入。

实机待验收：重载后分别从侧栏和设置页修改一个标记，核对另一页面自动更新；登记动态后核对两处显示；在设置页输入未保存笔记时，从侧栏修改标记，核对笔记仍在。

Chrome 扩展内部页面仍受当前浏览器工具访问限制，本轮不以模拟测试替代实际双窗口点选验收。重载 3.4.7 后需要重新打开设置页与侧栏，让新监听生效。

# 外链库数量与分类提交交接

日期：2026-09-17  
版本：3.5.1  
提交：`8bd9107 feat: 支持按外链分类启动批次`

## 问题原因

用户执行「从云端回读」后，云端 `sheetTableData` 实际仍为 2,975 行，没有被重复写入。旧界面同时合并了 185 条打包内置目录和 60 条 `urlList` 自定义入口，按目标键去重后显示 3,065 个目标，所以看起来变成了三千多。

本机运行缓存核对：

- 云端行：2,975。
- 云端规范化目标：2,973；Neil Patel 与 Product Hunt 各有首页和提交页，同属一个 host-scoped 目标。
- 自定义列表：60 条，其中只有 3 条不在云端库内。
- 打包内置目录：185 条，其中 170 条不是自定义列表重复项。
- 旧显示目标：3,065。
- 新显示目标：2,976，即 2,973 个云端目标加 3 条自定义补充。

## 修复

- 云端库存在时，外链库视图以云端行作为主数据，只补充不在云端的自定义入口，不再混入打包旧目录。
- Settings 和侧栏数量改为同时显示「云端行数 / 去重目标数 / 自定义补充数」，不再用一个模糊总数混合不同来源。
- 云端条目优先保留完整分类、费用、语言和质量元数据。

## 按分类提交

- 侧栏「外链」页选择分类后，启用「提交『分类名』」按钮。
- 点击后只为当前勾选的 Profile 构建该分类队列，并自动切到「批量」页显示任务和日志。
- 分类启动排除隐藏的打包旧目录，只使用侧栏可见的云端库和自定义补充。
- 已成功组合继续按 `destinationKey + Profile` 去重。
- `paid / skip / broken / deleted` 继续永久排除；登录、验证码、OTP 和人工处理继续停放；机会分、黑名单和域名年龄过滤继续生效。
- 是否只填表、并发数和无人值守设置沿用「批量」页当前配置。

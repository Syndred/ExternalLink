## 已真实完成

- Neon 项目 **ExternalLink Admin** 的 production 分支已执行 `cloud/worker/schema.sql`：4 张表、2 个索引均返回 `Statement executed successfully`。
- Cloudflare R2 已创建私有 bucket `externallink-media`。
- Cloudflare Worker **externallink-cloud** 已部署至 `https://externallink-cloud.syndred.workers.dev`；带设备密钥请求 `/v1/health?workspace=default` 回读 `{"ok":true,"workspaceId":"default","documentKeys":21}`。
- `DATABASE_URL`、`DEEPSEEK_API_KEY` 与 `APP_ACCESS_TOKEN` 仅存 Cloudflare Worker Secret；没有写入 Git、扩展包、`.env.example` 或本报告。
- 扩展已经移除 Google OAuth/同步、本机 Python Agent、`127.0.0.1:8790`、本机媒体预检依赖和相关旧测试。Neon 是 Profile、外链库、提交账本、时间线和备注的日常唯一来源；R2 是 Logo 和截图的私有来源。
- 状态写入使用 Neon 文档版本条件原子更新；回读数据按值去重，不会吞掉首次编辑；临时网络错误保留待写文档并自动退避重试；已删除外链的筛选状态也会随工作区同步。

## 首次迁移待验收

迁移源已经预检为：6 个 Profile、2,905 个外链站、29 条核验提交记录，以及 `/Users/syndred/Desktop/projects/media/` 下 30 个支持的图片（6 个 Logo、24 张截图）。

需要在 Chrome 重载 3.0.0 后，在 ExternalLink 设置的「云端数据中心」依次执行：

1. 填入 `https://externallink-cloud.syndred.workers.dev`，在设备密钥输入框直接粘贴当前剪贴板里的密钥，点击“连接云端”。
2. 先导出 JSON 备份，再点击“首次迁移到云端”。
3. 点击“从云端回读”，核对 Profile、外链、账本与时间线数量；随后运行 `tools/migrate-media-to-r2.mjs` 上传媒体并再次回读。

浏览器安全策略禁止自动打开或操作 `chrome-extension://` 设置页，所以这一步没有被伪称已完成。迁移完成前，保留现有本机缓存和表格作为只读灾备，不再进行双向同步。

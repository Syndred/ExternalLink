# 外链插件时间线升级报告（2026-09-05）

## 目标

把 Google Sheet 中外链与网站资料的现有字段完整带入插件，让每张外链卡片直观看到“哪个网站在什么时候提交、何时审核、何时上线、后来发生了什么”，并能继续追加笔记，不再靠两边手工维护同一份动态。

## 已完成

- `Link Submit`：保留每行全部原始字段、Record、Detail、Time、SubmitProject 和原始行号。
- Profile 子表：保留全部 Field / Content / Notes；已知字段继续映射到自动填表，未知字段也不会丢失。
- 外链卡片：显示提交网站、最近动态、各 Profile 当前标签、Sheet 原始字段和完整时间线。
- 时间线：按 `destinationKey + profileId` 分组，事件只追加不覆盖；支持已提交、待审核、已上线、被拒绝、需跟进、需人工、链接失效和笔记。
- 历史迁移：旧成功账本和 Link Submit 历史幂等导入；旧 Submit 只作为历史标记，不提升为未经证实的成功。
- 备份：JSON 包含成功账本、时间线、Profile、注释、URL 列表和 `sheetTableData` 快照；导入时间线采用追加合并。
- 数据库：不新增远程数据库，继续复用 `chrome.storage.local`。Google Sheet 保持人工维护源，插件缓存负责日常展示和运行。

## 数据边界

- 明确成功仍只接受 Agent 看见成功证据或用户人工确认。
- 提交、待审核、拒绝和跟进可作为时间线动态记录，但不会把缺少证据的旧数据伪造成上线成功。
- 同一外链站提交多个自家网站时，每个 Profile 都有独立时间线。

## 2.9.1 修正

- 日常查看只使用已应用的本地 Sheet 缓存，不需要启动本机 Agent；主动更新 Google、回写账本或开启自动检查时才需要。
- 外链库将“站点分类”和“提交/收录进度”拆成两个筛选器。
- 旧 `Link Submit.Submit` 显示为“表格有提交动作（未核验）”，不冒充有证据的成功或已收录。
- 每张卡片首屏常显 URL、提交网站、当前进度、提交时间、最近动态、Record、Detail 和补充备注。

## 2.9.2 离线快照

- 已从真实工作簿读取并内置 2026-09-05 快照：6 个项目、2,905 个外链站、29 条核验提交记录，`Link Submit` 首行保留 6 个原始字段。
- 重载扩展时若内置快照比运行缓存新，会自动更新 `chrome.storage.local`；不再要求用户为了查看数据而启动 Agent 或点击“应用同步”。
- “应用同步”改名为“更新本地缓存”，并移除其隐式 Google 回写；读取与回写操作边界分开。
